# 프론트엔드팀 계획서 — 사용자 정의 확인·블라인드 검증 GUI

- 문서 ID: `STR-P06-R2-FE-PLAN-01`
- 상태: PM 검토안

## 목적

사용자가 박스권 정의 초안과 대표 사례를 눈으로 확인하고, 새 표본에서 탐지 경계를 편향 없이 평가할 수 있게 한다. 화면 전체에 “박스권 단독 평가”임을 표시한다.

## 화면 계획

### 정의 확인 화면

- `VALID`, `PARTIAL`, `NOT_BOX` 대표 차트를 나란히 비교
- 사용자 최종 경계와 주요 특징을 동일 축으로 표시
- “필수/허용/제외 특징” 정의 문구별 동의·수정 의견 입력
- 시작·종료 경계 판단 사례의 쌍 비교
- 정의 초안 버전별 변경 내역 표시

### 블라인드 검증 화면

- 종목명, 표본층, 알고리즘 종류, 이후 가격을 평가 완료 전 숨김
- 후보 경계와 원자료만 표시하고 점수·예상 라벨은 숨김
- 직접 경계 생성, 시작·종료 수정, 유효/부분/비박스/자료부족 선택
- 확신도는 기본값 없이 의도적 선택을 요구
- 근거를 최소 1개 선택하고 `PARTIAL`, `INSUFFICIENT`에는 설명을 요구
- 이전·다음 이동, 임시 저장, 확정 전 검토 지원

### 결과 화면

- 수익률과 손실 장벽을 표시하지 않음
- 사용자 경계와 자동 경계의 겹침, 과포함, 누락 구간 표시
- 유형별 분류 성능, 경계 오차, 수정률, 반복 평가 일치도 표시
- 세트가 끝나기 전에는 누적 성능을 숨겨 후속 평가 편향을 방지

## 접근성·사용성 기준

- 경계 색상뿐 아니라 패턴·레이블로 구분
- 긴 수년 구간에서도 확대·축소 후 경계 날짜 확인 가능
- 키보드만으로 경계와 라벨 입력 가능
- 자동 저장 실패와 확정 상태를 명확히 표시
- 반복 항목임을 UI에서 노출하지 않음

## 산출물

- UI 흐름도와 화면 설계서
- 정의 확인·블라인드 평가·결과 화면
- 평가자 사용 매뉴얼
- 접근성·오류 복구·네트워크 E2E 증적

## 중단 조건

- 미래 가격이나 알고리즘 예상 라벨이 평가 전에 노출됨
- `BASE_ONLY`와 전체 패턴 평가가 시각적으로 구분되지 않음
- 장기 차트에서 사용자 경계를 정확히 수정할 수 없음
- 확정되지 않은 입력이 완료로 표시됨
