# QA·성과검증팀 계획서 — 박스권 이해·탐지 독립 검증

- 문서 ID: `STR-P06-R2-QA-PLAN-01`
- 상태: PM 검토안

## 검증 질문

1. 정의 가이드가 사용자의 실제 판단을 설명하는가?
2. 탐지기 v2가 처음 보는 종목·기간에서도 유효 박스를 찾아내는가?
3. 사용자가 의도한 시작·종료 경계와 충분히 겹치는가?
4. 작은 데이터 변화에 경계가 비정상적으로 흔들리지 않는가?
5. 평가 절차와 구현에 미래 데이터 누수가 없는가?

이번 검증은 이후 수익률, 급등 성공률, 손실률, 자동매매 성과를 질문하지 않는다.

## 사전 등록 지표

### 분류

- `VALID + PARTIAL` 양성 기준 precision, recall, F1
- `VALID` 단독 precision과 recall
- hard negative 오탐률
- 계층별 혼동행렬

### 경계

- interval IoU
- 사용자 구간 대비 자동 구간 과포함률·누락률
- 시작·종료 경계 거래일 오차
- 경계 미수정·소폭 수정·대폭 수정 비율

### 일관성·안정성

- 숨은 반복 12개의 라벨 일치율과 경계 IoU
- 동일 입력 재실행 100% 일치
- 마지막 1~5개 봉 제거·추가 시 경계 민감도
- 파라미터 인접값에서 후보 급변 비율

## PM 권고 통과선

- `VALID + PARTIAL` precision 75% 이상
- hard negative 오탐률 20% 이하
- 중앙 interval IoU 0.65 이상
- 종료 경계 중앙 오차 10거래일 이하
- 대폭 경계 수정률 30% 이하
- 반복 라벨 일치율 80% 이상
- 재현성·미래 차단·주문 격리 100%

표본 수가 작아 단일 수치 근처의 통과·실패를 기계적으로 판단하지 않는다. 각 지표의 분모와 표본층, 신뢰구간, 실패 사례를 함께 PM에 제출한다. 시작 경계 오차는 장기 박스 특성상 보고 지표로 두되 단독 차단선으로 삼지 않는다.

## 독립성 통제

- 세트 C는 탐지기와 파라미터 동결 후 한 번만 공개
- 실패 결과를 본 뒤 같은 세트에 맞춰 수정하면 해당 세트는 폐기하고 새 검증 세트를 구성
- 알고리즘 개발자는 숨은 반복 매핑과 표본층을 평가 완료 전 확인하지 않음
- 제외는 사전 품질 규칙으로만 결정

## 산출물

- 사전 등록 검증 규격
- 자동 테스트와 GUI E2E 결과
- 혼동행렬·경계 분포·실패 사례 보고서
- 정의 이해 여부와 탐지기 통과/보완/폐기 의견
- 다음 단계 승인 또는 보류 권고

## 중단 조건

- 세트 C가 구현 전에 노출됨
- 검증 도중 지표나 통과선을 결과에 맞춰 변경함
- 누수·재현성·주문 격리 시험 중 하나라도 실패함
- 평가 미완료 항목을 정상 결과로 집계함
