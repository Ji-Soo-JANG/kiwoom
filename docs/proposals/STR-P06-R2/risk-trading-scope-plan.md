# 위험관리·매매시스템팀 계획서 — 연구 범위 차단

- 문서 ID: `STR-P06-R2-RISK-TRD-PLAN-01`
- 상태: PM 검토안

## 공동 결론

이번 단계는 박스권 하위 탐지기의 정의·재현성 검증이다. 아직 급락, 회복, 눌림과 실제 진입 시점이 결합되지 않으므로 매매 성과와 손실 정책을 평가할 수 없다.

## 제외·차단 항목

- 다음 거래일 종가를 가상 진입가로 사용하지 않음
- 임의 +10%/-5% 장벽을 전략 목표·손절로 사용하지 않음
- MFE·MAE·수익률로 박스권 정의를 선택하지 않음
- PAPER/LIVE 주문 후보 생성 금지
- 자동매매 ON/OFF와 전략 승격 상태 변경 금지
- 자금 배분, 손절률, 보유기간, 주문 방식 연구 제외

## 검토 역할

- 연구 API와 주문 API 사이 의존성 검토
- DB 이벤트나 스케줄러가 평가 결과를 주문 후보로 소비하지 않는지 확인
- 문서와 GUI에서 박스권 단독 검증을 매수 추천으로 오해할 표현 제거
- 다음 전체 패턴 단계로 넘어갈 때 새 위험관리 승인 필요성을 명시

## 산출물

- 주문 경로 비연결 증적
- 금지 의존성 검사 결과
- 잘못된 성과 해석과 UI 문구 검토표
- 전체 패턴 검증 전환 시 필요한 별도 승인 체크리스트

## 중단 조건

- 평가 결과가 자동매매 후보나 전략 점수로 자동 반영됨
- 손실·수익 기준이 박스권 정의의 정답으로 사용됨
- 연구 기능 실행이 계좌·주문 상태를 변경함
