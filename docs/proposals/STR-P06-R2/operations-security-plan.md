# 운영·보안팀 계획서 — 로컬 연구 운영과 접근 통제

- 문서 ID: `STR-P06-R2-OPS-SEC-PLAN-01`
- 상태: PM 검토안

## 목적

박스권 정의·평가 자료를 사용자 로컬 환경에서 재현 가능하게 운영하고, 계좌 비밀이나 실주문 권한 없이 연구 기능만 실행되도록 통제한다.

## 운영 계획

- PostgreSQL, 백엔드, 프론트엔드의 평가 전용 실행 순서와 상태 점검 절차를 문서화한다.
- 평가 배치 생성 전 DB 백업 또는 복구 가능한 스냅샷을 확인한다.
- 알고리즘·파라미터·표본 명세·입력 해시·Git 커밋을 한 실행 기록으로 묶는다.
- 평가 중 서버 중단 후 재기동해도 확정·미확정 상태가 정확히 복원되는지 점검한다.
- 평가 세트 완료 전 성능 집계와 숨은 반복 매핑은 일반 UI에서 조회하지 못하게 한다.

## 보안·비밀 관리

- 키움 API 키·시크릿, 계좌정보, 로그인 비밀번호는 Git과 연구 문서에 기록하지 않는다.
- 박스권 연구 실행에는 외부 주문 권한이 없는 설정을 사용한다.
- 개발용 인증 비밀번호는 환경변수로만 주입하고 보고서에는 실제 값을 남기지 않는다.
- 연구 API는 인증 사용자를 요구하고 평가 원본 변경·성과 공개 요청을 감사 기록으로 남긴다.
- DB `repair` 같은 운영 조치는 사전 구조 대조와 별도 승인 없이는 실행하지 않는다.

## 산출물

- 평가 전용 로컬 실행 매뉴얼
- 배치별 실행·버전·해시 감사 기록
- 재기동·복구 시험 결과
- 비밀정보 Git 추적 여부 점검표
- 연구 전용 권한과 주문 비연결 확인서

## 중단 조건

- 실계좌 비밀이나 주문 권한 없이는 연구 화면을 실행할 수 없는 구조
- 평가 세트 또는 사용자 경계를 재현할 버전·해시가 누락됨
- 숨은 검증 정보가 평가 완료 전에 노출됨
- 비밀값이 로그, 문서, Git 변경에 포함됨
