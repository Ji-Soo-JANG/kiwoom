# STR-P06 배치 1 결과 정정 기록

- 문서 ID: `STR-P06-R2-PM-CORR-01`
- 정정일: 2026-08-30
- 상태: 공식 정정

## 정정 사유

기존 결과 보고서는 박스권 정의 라벨과 기준일 이후 수익률·장벽을 함께 해석해 전체 전략 성과처럼 표현했다. 그러나 사용자가 평가한 것은 전체 `급락 → 박스권 → 회복 → 눌림` 전략이 아니라 박스권의 정의였다. 따라서 손실 장벽과 이후 수익은 정의의 근거가 될 수 없다.

추가로 배치 1의 30건 중 29건에서 최종 경계가 `2026-05-12`~`2026-07-22`로 동일했다. 항목 전환 시 입력 폼이 초기화되지 않아 이전 경계가 다음 항목에 남는 UI 결함과 일치한다. 이 경계들은 종목별 사용자 의도 경계로 간주할 수 없다.

## 사용할 수 있는 자료

- 사용자 라벨 30건의 탐색적 분포
- 라벨과 함께 저장된 사유 코드
- `STABLE_RANGE`, `LOW_SLOPE`, `BOUNDARY_AMBIGUOUS`, `VOLUME_SPIKES`가 어떤 라벨과 함께 나타났는지에 대한 정성 가설

## 사용 금지 자료와 결론

- 동일하게 오염된 29건 경계로 계산한 경계 정확도·기간 선호
- 기준일 이후 수익률, MFE·MAE, 목표·손실 장벽으로 박스권 정의를 선택하는 결론
- 배치 1 결과를 전체 패턴 전략의 성공률·이율·승격 근거로 표현하는 것
- 기존 30건을 독립 검증 자료로 재사용하는 것

## 시정 조치

- 평가 확정 후 폼 초기화와 다음 항목 자동 이동을 구현하고 테스트함
- 확신도 기본값을 제거하고 명시 선택하도록 변경함
- 부분 유효·자료 부족은 설명을 필수로 변경함
- 정의 검증 화면에서 미래 결과 공개 기능을 제거함
- 기존 배치와 중복 없는 신규 배치 B 20건을 별도 생성함

이 정정은 과거 기록을 삭제하지 않는다. 기존 문서는 역사적 기록으로 보존하되, 본 정정 문서가 범위와 해석에서 우선한다.
