# 전략연구팀 계획서 — 사용자 박스권 정의 이해와 탐지기 v2

- 문서 ID: `STR-P06-R2-STR-PLAN-01`
- 상태: PM 검토안
- 연구 대상: 전체 전략의 두 번째 단계인 `박스권`만

## 목적

기존 30개 평가에서 사용자가 선택·수정한 경계를 분석해 “사용자가 박스권이라고 보는 가격 상태”의 정의 가설을 만든다. 이 가설을 사용자에게 차트와 함께 먼저 확인받은 후에만 탐지기 v2를 설계한다. 박스권 이후 수익률이나 매수 타이밍은 정의 근거로 사용하지 않는다.

## 기존 자료에서 확인할 항목

- `VALID_BOX`, `PARTIAL_BOX`, `NOT_BOX`, `INSUFFICIENT_DATA`별 가격 구조
- 사용자 최종 시작·종료 경계와 NARROW/EXPANDED/CONNECTED 원본 경계 차이
- 가격 중앙대역, 체류율, 기울기, 변동성, 이탈의 길이와 복귀 여부
- 간헐적 거래량 급증 횟수·간격·급증 후 가격 상태 유지 여부
- 급락 직후 가격 발견 구간을 시작 경계에 포함하는지
- 회복 시작 구간을 종료 경계에서 어디까지 제외하는지
- 장기 박스 안의 짧은 하위 박스를 하나로 연결하는지 분리하는지

기존 평가는 확신도가 모두 3이고 메모가 없으므로 숫자 상관만으로 정의를 확정하지 않는다. 대표 쌍 비교와 경계 재확인으로 의미를 보충한다.

## 정의 확인 절차

1. 사용자 경계 30개에서 공통 특징과 충돌 특징을 추출한다.
2. `VALID↔NOT`, `VALID↔PARTIAL`, 장기 연결↔분리 사례를 각 3쌍 이상 선정한다.
3. GUI에서 두 차트를 나란히 보여주고 “어떤 차이가 박스권 여부를 바꿨는지” 확인한다.
4. 다음 형식의 정의 초안을 만든다.
   - 필수 특징
   - 허용 특징
   - 즉시 제외 특징
   - 시작 경계 판단
   - 종료 경계 판단
   - 불확실·부분 박스 처리
5. 사용자가 정의 초안과 대표 사례를 승인한 뒤 탐지기 v2 설계로 넘어간다.

## 탐지기 v2 연구 방향

- 기간 후보 60~1,200일 중 선택하는 방식을 주 탐지 방식에서 제거한다.
- 최신 시점부터가 아니라 가격 수준·변동성·체류율의 변화점을 이용해 안정 상태 후보를 찾는다.
- 박스 길이는 입력 제한이 아니라 검출 결과로 기록한다.
- 거래량 급증은 단순 횟수가 아니라 급증 후 가격대 유지와 함께 평가한다.
- 짧은 이탈과 구조적 가격 상태 변화를 구분한다.
- 단일 정답 점수뿐 아니라 경계 신뢰도와 불확실 사유를 반환한다.
- 급락·회복·눌림 정보는 후보 해석용 문맥으로 표시할 수 있지만 박스권 정답 라벨을 대신하지 않는다.

## 연구 성공 기준 제안

- 새 블라인드 표본에서 `VALID + PARTIAL` 탐지 정밀도 75% 이상
- hard negative의 오탐률 20% 이하
- 사용자 최종 구간과 중앙 interval IoU 0.65 이상
- 종료 경계 중앙 오차 10거래일 이하
- 자동 경계를 큰 폭으로 다시 고친 비율 30% 이하
- 동일 입력·버전의 후보와 특징 재현율 100%

박스권 시작은 수개월~수년 범위에서 사용자도 허용 폭이 클 수 있으므로 시작일 절대 오차는 공개하되 단독 탈락 기준으로 사용하지 않는다. 위 수치는 PM 권고안이며 사용자 승인 전 확정값이 아니다.

## 산출물

- 특징 사전과 정의-특징 추적표
- 탐지기 v2 알고리즘 설계서 및 파라미터 버전
- 기존 30개에 대한 재현 비교 보고서

## 중단 조건

- 대표 사례에 대한 사용자 정의가 서로 모순되며 조율되지 않음
- 데이터 품질 문제와 정의 차이를 구분할 수 없음
- 미래 가격이나 이후 수익을 사용해야만 후보를 맞출 수 있음
- 기존 30개에만 과적합되고 새 보정 표본에서 즉시 붕괴함
