# PM 통합 보고 및 승인 요청서 — STR-P06-R2

- 문서 ID: `STR-P06-R2-PM-01`
- 상태: **사용자 승인 대기**
- 기준일: 2026-08-29
- 구현 상태: 미착수

## 1. 사용자 의도

최종 목적은 `급락 → 박스권 → 회복 → 눌림` 전체 패턴을 찾는 것이다. STR-P06-R2의 역할은 그중 박스권 하위 구간에 대해 다음 두 질문만 검증하는 것이다.

1. 프로젝트가 사용자가 말하는 박스권을 제대로 이해했는가?
2. 그 정의에 맞는 구간을 처음 보는 실제 차트에서도 찾아내는가?

박스권 라벨 이후 가격 상승 여부, 손실 장벽, 매수 시점과 전체 전략 수익성은 이번 질문이 아니다.

## 2. PM 현황 판단

기존 30개 평가는 사용자 경계 자료를 확보했다는 점에서 유효하다. 그러나 확신도가 모두 3이고 메모가 없으며 자동 후보 30개 중 29개가 수정돼, 현재 알고리즘이 정의를 이해했다고 판단할 수 없다. 또한 기존 성과 보고서가 박스권 기준일 이후 가격을 전략 성과처럼 해석한 부분은 별도 정정이 필요하다.

따라서 기존 30개는 탐지기 개발용 보정 세트로만 사용하고 독립 성능 근거로 재사용하지 않는다.

## 3. 부서 합의안

| 단계 | 내용 | 사용자 승인 지점 |
|---|---|---|
| 0. 문서 정정 | 기존 결과 보고서에서 전략 수익·손실 결론 철회 | 본 승인에 포함 |
| 1. 정의 이해 | 기존 30개 분석, 대표 쌍 비교, 정의서 v1 작성 | 정의서 별도 확인 |
| 2. 정의 확인 | 신규 20개로 사용자 정의 초안 보정 | 탐지기 구현 전 확인 |
| 3. 탐지기 v2 | 변화점·가격상태·거래량 사건 기반 동적 경계 구현 | 승인된 정의만 사용 |
| 4. 독립 검증 | 신규 60개 + 숨은 반복 12개 블라인드 평가 | 결과 공개 전 알고리즘 동결 |
| 5. PM 보고 | 분류·경계·일관성·실패 사례 통합 | 다음 전체 패턴 단계 승인 요청 |

## 4. PM 권고 검증 기준

- 유효·부분 박스 탐지 정밀도 75% 이상
- hard negative 오탐률 20% 이하
- 사용자 경계와 중앙 IoU 0.65 이상
- 종료 경계 중앙 오차 10거래일 이하
- 대폭 경계 수정률 30% 이하
- 숨은 반복 라벨 일치율 80% 이상
- 미래 데이터 차단, 재현성, 주문 격리 100%

박스 시작일의 절대 오차는 수개월~수년 구간 특성을 고려해 공개하되 단독 통과선으로 사용하지 않는다. 기준값은 사용자 승인 전 권고안이며, 정의 확인 단계에서 변경이 필요하면 결과를 보기 전에 새 버전으로 기록하고 재승인받는다.

## 5. 포함 범위

- 기존 보고서 목적·결론 정정
- 사용자 박스권 정의서와 대표·반례 사례집
- 기존 30개 경계 연구 데이터셋
- 정의 확인용 20개 평가
- 동적 박스권 탐지기 v2 연구 구현
- 독립 60개와 숨은 반복 12개 평가
- 정의·분류·경계·일관성 검증 보고서
- 각 부서 검토 자료와 PM 완료 보고

## 6. 제외 범위

- 급락·회복·눌림 전체 패턴 탐지기 변경
- 이후 수익률·MFE·MAE·목표·손실 장벽 평가
- PAPER/LIVE 주문과 자동매매 연결
- 전략 승격, 자금 배분, 손절·익절 정책
- AI 자동 학습과 운영 파라미터 자동 변경

## 7. 주요 위험과 대응

| 위험 | 대응 |
|---|---|
| 기존 30개 과적합 | 독립 세트 C 완전 분리 |
| 사용자의 정의를 숫자로 성급히 고정 | 대표 쌍과 정의 문구를 먼저 승인 |
| 박스 길이를 고정 규칙으로 재도입 | 기간은 결과값, 변화점과 가격 상태 중심 |
| 이후 가격으로 정의를 선택 | 모든 수익·장벽 지표를 이번 검증에서 제외 |
| 평가 피로 | 20개 정의 확인과 72회 독립 평가를 별도 회차로 진행 |
| 단일 기준일 편향 | 5개 이상 기준일 층화 |
| 평가자 판단 변화 | 숨은 반복 12개로 자기 일치도 측정 |

## 8. 단계별 보고 원칙

- 단계 1의 정의서가 사용자 확인을 받기 전 탐지기 v2 구현에 착수하지 않는다.
- 탐지기 v2와 파라미터를 동결하기 전 독립 검증 세트를 공개하지 않는다.
- 독립 검증 실패를 숨기거나 같은 세트에 맞춰 수정하지 않는다.
- 완료 보고는 성공 사례와 함께 오탐·누락·경계 실패 사례를 동등하게 포함한다.
- 이번 단계 완료는 전체 패턴이나 자동매매 전략의 성공을 뜻하지 않는다.

## 9. PM 승인 요청

> **STR-P06-R2를 박스권 하위 정의 이해·탐지 검증 단계로 승인한다. 기존 30개는 보정 자료로만 사용하고, 사용자 정의서 확인 후 동적 탐지기 v2를 구현한다. 이후 시점 일관 신규 60개와 숨은 반복 12개로 분류·경계·일관성을 검증한다. 수익률·손실 장벽·전체 전략·주문 연결은 범위에서 제외한다.**

승인 후에도 단계 1에서 작성한 `사용자 박스권 정의서 v1`은 사용자에게 별도로 보여주고 확인받은 뒤 다음 구현으로 진행한다.
