# 제안 및 승인 대기 문서

이 디렉터리는 부서 검토를 거쳐 PM이 사용자에게 승인을 요청하는 안건을 보관한다. 제안서의 `승인 대기` 상태는 구현 승인을 뜻하지 않는다. 사용자가 승인한 뒤에만 구현 계획과 코드 변경을 시작한다.

## 안건

| 안건 | 내용 | 상태 |
|---|---|---|
| [STR-P06](STR-P06/proposal.md) | 실제 DB 일봉 기반 사용자 박스권 평가 워크벤치 | [30개 파일럿 완료·알고리즘 승격 보류·R2 승인 대기](STR-P06/pilot-result-report-v1.md) |

## 상태 정의

- `부서 검토 중`: 담당 부서가 근거와 위험을 작성하는 단계
- `사용자 승인 대기`: PM 검토가 끝나 구현 여부와 범위를 사용자에게 묻는 단계
- `승인`: 승인 기록에 범위·조건·일시를 남긴 상태
- `보류` 또는 `반려`: 구현하지 않으며 사유와 재검토 조건을 남긴 상태
- `완료`: 승인 범위의 구현·검증·부서 확인이 끝난 상태
