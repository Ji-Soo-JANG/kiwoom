# STR-P06 미래 성과 평가 정책 v1

- 문서 ID: `STR-P06-OUTCOME-POLICY-01`
- 정책 ID: `box-outcome-v1`
- 사전 등록일: 2026-08-29
- 상태: **잠금**
- 적용 대상: 미래 가격을 보지 않고 확정한 STR-P06 평가
- 비목적: 실제 매매손익, 전략 승격, 주문 실행, 수익 보장

## 1. 목적과 원칙

이 정책은 “박스권으로 보이는가”라는 당시 판단과 이후 가격 움직임을 분리해 비교한다. 결과를 본 뒤 유리한 기간·가격·표본만 선택하지 못하도록 기준가격, 관측기간, 장벽, 결측 처리와 반올림을 공개 전에 고정한다.

결과는 탐지 패턴 연구 자료다. 체결, 주문 수량, 비용, 슬리피지와 자금 제약을 반영하지 않으므로 매매전략 손익으로 해석하지 않는다.

## 2. 계산 자격

다음을 모두 만족해야 한다.

1. 항목과 사용자 평가가 `COMMITTED` 상태다.
2. 평가 입력에는 `trade_date <= cutoff_date`만 존재한다.
3. 입력 해시, 데이터·후보 생성기·라벨 버전이 연결돼 있다.
4. cutoff 이후 서로 다른 유효 거래일 OHLCV가 20개 이상 존재한다.
5. 기존 공개 결과가 없거나, 있다면 새로 계산하지 않고 기존 스냅샷을 반환한다.
6. 가격은 양수이고 `low <= open/close <= high`를 만족한다.

20거래일 미만은 성과 0이 아니라 `관측 미완료`다. 부분 성과를 최종 결과처럼 공개하지 않는다.

## 3. 시점과 공식

| 기호 | 정의 |
|---|---|
| `cutoffDate` | 사용자가 볼 수 있던 마지막 거래일 |
| `P0` | cutoff 이후 첫 저장 거래일의 종가 |
| `Pn` | 진입 기준일부터 n번째 거래일 종가 |
| `Hn` | 첫 n거래일의 최고 고가 |
| `Ln` | 첫 n거래일의 최저 저가 |

휴장일과 주말은 세지 않는다. DB의 서로 다른 거래일 순서를 사용한다. 관측 지평은 5·10·20거래일로 고정한다.

```text
CloseReturn(n) = Pn / P0 - 1
MFE(n)         = Hn / P0 - 1
MAE(n)         = Ln / P0 - 1
```

MFE의 고가에 체결됐다고 가정하지 않으며, MAE도 실제 손절 손실을 뜻하지 않는다.

## 4. 최초 장벽

- 목표: `high >= P0 × 1.10`
- 무효화: `low <= P0 × 0.95`
- 첫 20거래일을 날짜순으로 검사한다.
- 목표만 먼저 관측: `TARGET`
- 무효화만 먼저 관측: `INVALIDATION`
- 같은 일봉에서 둘 다 관측: `AMBIGUOUS`
- 모두 미관측: `NONE`

일봉으로 같은 날의 장중 순서를 알 수 없으므로 `AMBIGUOUS`를 성공으로 계산하지 않는다.

## 5. 정밀도와 예시

- 저장: 소수점 아래 6자리 비율
- UI: 백분율 소수점 2자리
- 가격: 저장된 정수 일봉 가격
- 동일 입력·버전의 결과는 결정론적이어야 한다.

`P0=10,000`, 5일째 종가 `10,500`, 기간 최고 `11,200`, 최저 `9,600`이면 종가수익률 5%, MFE 12%, MAE -4%다.

## 6. 데이터 이상 처리

| 상태 | 처리 |
|---|---|
| 20거래일 미만 | 계산 중단, 관측 미완료 |
| 중복 거래일 | 품질 실패, 계산 금지 |
| 0·음수 가격/잘못된 OHLC | 품질 실패, 계산 금지 |
| 거래량 0 | 가격 계산 가능, 별도 품질 경고 |
| 거래정지·장기 공백 | 달력일을 보충하지 않고 실제 행 사용, 공백 경고 |
| 기업행사 의심 단절 | 현재 외부자료 범위 밖이므로 자동 보정 없이 검토 상태 |
| 평가 입력 해시 불일치 | 공개 금지, 새 평가 ID로 재평가 |

나쁜 성과를 이유로 제외할 수 없다. 제외는 공개 전에 고정한 품질 사유만 허용하며 제외 전후 수와 사유를 보고한다.

## 7. 불변 저장과 재현

평가 ID, 종목, cutoff, 기준일·가격, 5·10·20일 지표, 최초 장벽과 정책 버전을 JSON 스냅샷으로 저장한다. 요청자와 공개 시각은 reveal 감사 기록에 남긴다. 동일 평가에는 하나의 reveal만 허용하며 재요청은 기존 결과를 반환한다. 데이터·산식 변경도 기존 결과를 덮어쓰지 않는다.

## 8. 표본 정책

| 세트 | 목적 | 제한 |
|---|---|---|
| 사용자 사례 | 의도 파악 | 단독 공식 성과 금지 |
| 전략 후보 | 현 탐지기 분포 | 탐지 편향 표시 |
| 반례 | 오탐·안전 실패 | 반드시 포함 |
| 무작위/전수 | 시장 분포 | 공식 비교 중심 |
| 골든 회귀 | 판정 안정성 | 파라미터 최적화 금지 |
| 봉인 시간외 | 일반화 확인 | 공개 후 재사용 기록 |

과제 생성 시 표본 정책 JSON, 데이터·생성기 버전, 종목·cutoff와 입력 해시를 저장한다. 결과 확인 후 같은 과제의 구성·제외 기준을 변경하지 않는다.

## 9. 해석 제한

- 지정가·호가·미체결·상하한가·VI·거래정지·비용·세금·슬리피지를 반영하지 않는다.
- 다음 날 종가 체결을 가정하지 않는다.
- 작은 표본의 평균·적중률을 확정적으로 해석하지 않는다.
- 사용자 라벨과 수익의 일치는 인과관계를 증명하지 않는다.
- 실전 승격은 체결·비용·자금·위험 모델과 별도 사용자 승인이 필요하다.

## 10. 새 버전이 필요한 변경

기준가격, 관측기간, 장벽 비율, 같은 날 처리, 수정주가·기업행사 보정, 비용·체결 모델 또는 부분 공개 규칙을 바꾸면 `v2` 이상을 만들며 v1을 재작성하지 않는다.

## 11. 필수 검증

- 20거래일 부족 차단
- 5·10·20일 공식 수치
- TARGET/INVALIDATION/AMBIGUOUS/NONE
- cutoff 이하·이후 데이터 분리
- 공개 멱등성과 불변 저장
- 공개 전 미래 필드 부재
- 연구 패키지의 주문 서비스·테이블 비의존
