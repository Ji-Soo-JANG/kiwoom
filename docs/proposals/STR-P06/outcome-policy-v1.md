# STR-P06 미래 성과 정책 v1

- 정책 ID: `box-outcome-v1`
- 사전 등록일: 2026-08-29
- 상태: 잠금

기준일 다음 거래일의 종가를 연구 기준가격으로 사용한다. 5·10·20거래일의 종가수익률, 기간 중 최고가 기준 MFE, 최저가 기준 MAE를 계산한다. 목표 장벽은 +10%, 무효화 장벽은 -5%다. 두 장벽이 같은 일봉에서 함께 관측되면 장중 순서를 알 수 없으므로 `AMBIGUOUS`로 기록한다. 20거래일이 쌓이기 전에는 결과를 공개하지 않는다.

이 값은 탐지 패턴의 이후 가격 연구를 위한 것이며 실제 체결, 비용, 슬리피지와 세금을 반영한 매매수익이 아니다. 정책 변경은 기존 결과를 덮어쓰지 않고 새 버전으로 만든다.

평가 세트는 사용자 사례, 반례, 무작위/전수, 골든 회귀, 봉인 시간외 세트로 구분한다. 각 과제의 `sampling_policy_json`, 데이터 버전, 입력 해시와 후보 생성기 버전을 확정 전에 저장한다. 성과를 본 뒤 표본을 제외하거나 같은 버전의 규칙을 바꾸지 않는다.
