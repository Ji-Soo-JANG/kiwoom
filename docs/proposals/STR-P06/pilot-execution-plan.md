# STR-P06 실제 데이터 파일럿 실행 승인 요청서

- 상태: **사용자 실행 승인 대기**

## 제안

개발 PostgreSQL의 저장 일봉에서 30개 평가 항목을 만든다. 사용자 지정 10개, 전략 후보 10개, 무작위·반례 10개로 나누고 종목별 기준일은 미래 20거래일이 존재하는 과거 날짜로 정한다. 사용자는 GUI에서 미래를 보지 않고 먼저 라벨링하며, 과제 완료 뒤 결과를 공개한다.

파일럿은 알고리즘 승격이나 매매 연결이 아니다. 목적은 후보 경계가 사용자의 박스권 정의와 얼마나 일치하는지, GUI가 실제 자료에서 충분한지 확인하는 것이다.

## 산출물

- 30개 항목의 잠긴 평가 과제와 입력 해시
- 후보 유형별 선택률·거절률·경계 수정 거리
- 사용자 라벨과 반복 라벨 일치도
- `box-outcome-v1` 후속 결과 비교
- 데이터 부족·품질 문제·GUI 개선 목록
- 부서 검토와 다음 알고리즘 조정 승인안

## 승인 요청 문구

> **개발 PostgreSQL 실제 일봉으로 30개 항목의 STR-P06 파일럿 평가 과제를 생성하고, 미래 데이터 비공개 상태에서 사용자 평가를 진행할 수 있게 한다. 결과는 연구 자료로만 사용하며 전략 승격·주문에는 연결하지 않는다.**
