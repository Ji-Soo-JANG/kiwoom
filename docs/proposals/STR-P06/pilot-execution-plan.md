# STR-P06 실제 데이터 파일럿 실행 계획서

- 상태: **승인됨 / 평가 배치 준비 완료 / 사용자 블라인드 평가 대기**
- 승인일: 2026-08-29
- 실제 배치 ID: `1`

## 제안

개발 PostgreSQL의 저장 일봉에서 30개 평가 항목을 만든다. 최신 전략 스캔의 우선 검토군 10개, 근접 비교군 10개, 결정론적 무작위 대조군 10개로 나눴다. 사용자가 직접 지정한 종목은 아직 없으므로 이를 사용자 지정군이라고 기록하지 않는다. 기준일은 모든 종목에 미래 20거래일이 존재하는 `2026-07-23`으로 고정했다. 사용자는 GUI에서 미래를 보지 않고 먼저 라벨링하며, 과제 확정 뒤에만 결과를 공개한다.

파일럿은 알고리즘 승격이나 매매 연결이 아니다. 목적은 후보 경계가 사용자의 박스권 정의와 얼마나 일치하는지, GUI가 실제 자료에서 충분한지 확인하는 것이다.

## 산출물

- 30개 항목의 잠긴 평가 과제와 입력 해시
- 후보 유형별 선택률·거절률·경계 수정 거리
- 사용자 라벨과 반복 라벨 일치도
- `box-outcome-v1` 후속 결과 비교
- 데이터 부족·품질 문제·GUI 개선 목록
- 부서 검토와 다음 알고리즘 조정 승인안

## 승인 요청 문구

> **개발 PostgreSQL 실제 일봉으로 30개 항목의 STR-P06 파일럿 평가 과제를 생성하고, 미래 데이터 비공개 상태에서 사용자 평가를 진행할 수 있게 한다. 결과는 연구 자료로만 사용하며 전략 승격·주문에는 연결하지 않는다.**

2026-08-29 사용자 승인에 따라 위 범위로 실행했다. 표본과 재현 규칙은 [표본 명세서](pilot-sample-manifest-v1.md), 생성·검증 결과는 [준비 완료 보고서](pilot-preparation-report.md)에 고정한다.
