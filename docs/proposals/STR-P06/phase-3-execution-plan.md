# STR-P06 3단계 검증 자료화 실행 승인 요청서

- 상태: **사용자 실행 승인 완료 · 성과 공개 기반 완료 · 실제 데이터 검증 미완료**
- 목표: 실제 DB 사례를 평가 세트로 구성하고, 미래 성과 산식을 사전 고정한 뒤 후보 알고리즘과 사용자 판단을 공정하게 비교한다.

## 승인 요청 범위

1. 사용자 사례·반례·무작위/전수·골든·봉인 세트 분리
2. 평가 계획, 표본 생성 규칙, 제외 기준과 내용 해시 잠금
3. 사용자 라벨 반복 평가와 경계·라벨 일치도 보고
4. 5·10·20 거래일 MFE/MAE 및 목표·무효화 선도달 산식의 사전 등록
5. 결과 공개 스냅샷 계산과 GUI 공개 화면
6. 후보 유형별 탐지 품질·후속 가격 결과 비교
7. 미래 누수·선택 편향·주문 분리 통합 시험
8. 실제 PostgreSQL 개발 데이터 E2E와 부서별 검토 보고

이번 단계도 주문, 자동매매, 전략 자동 승격에는 연결하지 않는다. 성과 산식과 표본 규칙은 결과를 확인하기 전에 잠그며, 변경 시 새 버전을 만든다.

## 승인 요청 문구

> **STR-P06 3단계 검증 자료화를 위 범위로 구현한다. 결과를 보기 전에 성과 산식과 표본 규칙을 고정하고, 주문·자동매매·전략 승격은 별도 승인 없이는 연결하지 않는다.**
