## 3. 구현 산출물

### 백엔드

- `BoxOutcomeCalculator`: cutoff 이후 20거래일 계산
- `BoxEvaluationOutcome`: 정책·기준가격·기간별 지표·장벽 계약
- `findOutcomeCandles`: cutoff 초과 행만 날짜순 조회
- `findReveal`: 기존 불변 결과 재사용
- `reveal/outcome`: 확정 확인, 계산·저장·재조회
- 명시적 공개 및 결과 조회 API

### 프론트엔드

- 사용자 요청 때만 공개 API 호출
- `미래 결과 공개` 버튼
- 정책 버전·기준가격·최초 장벽
- 5·10·20일 종가수익률·MFE·MAE 표

## 4. 처리 흐름

```text
블라인드 평가 확정
→ COMMITTED 확인
→ 사용자 명시적 공개
→ 기존 reveal이면 그대로 반환
→ 없으면 cutoff 초과 20거래일 조회
→ outcome-v1 계산·불변 저장
→ REVEALED 전이
→ GUI 표시
```

확정 전에는 결과를 계산하지 않으며 브라우저에 숨겨진 미래 데이터도 보내지 않는다.

## 7. 제한과 위험

1. 기준가격은 체결가격이 아니라 다음 거래일 종가다.
2. 일봉으로 같은 날 장벽 선후를 알 수 없다.
3. 기업행사 외부자료가 없어 가격 단절을 자동 보정하지 않는다.
4. 비용·슬리피지·유동성·호가가 반영되지 않는다.
5. 30개 파일럿은 수익성 확정에 매우 작다.
6. 단일 사용자 라벨은 객관적 정답이 아니다.
7. 파일럿 전에는 후보 유형과 GUI의 실제 유용성을 확정할 수 없다.
