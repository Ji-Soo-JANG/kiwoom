# 시점 기준 종목 유니버스

전략 연구에서 현재 상장 종목만 과거에도 존재했다고 가정하는 생존편향을 줄이기 위해 전체 종목 목록을 날짜별로 저장한다.

## 저장 규칙

- 키움에서 전체 종목 목록을 정상적으로 새로 받은 날에만 `stock_master_snapshot`에 저장한다.
- 인증 실패 등으로 캐시된 목록을 대신 사용한 실행은 그날의 실제 목록으로 간주하지 않는다.
- 같은 날짜에 다시 수집하면 해당 날짜 스냅샷을 원자적으로 교체한다.

## 과거 전략 조회

`GET /api/kiwoom/strategy-candidates?boxRangeDays=60&asOf=2026-08-21`

- 기준일 이하에서 가장 최근에 저장된 종목 스냅샷을 사용한다.
- 기준일 이하의 일봉만 분석하고 데이터 기준일도 그 범위 안에서 계산한다.
- 기준일 이전 스냅샷이 없으면 후보를 반환하지 않는다. 현재 종목 목록으로 과거를 추정하지 않는다.

## 데이터 한계

이 기능을 도입하기 전에 이미 상장폐지된 종목은 키움의 현재 종목 목록만으로 복원할 수 없다. 완전한 장기 백테스트를 하려면 거래소의 과거 상장·상장폐지 이력 또는 신뢰할 수 있는 별도 데이터 공급자가 필요하다.
