# 이벤트 기반 백테스트

현재 전략이 과거 시점에 만든 신호를 일봉 순서대로 재생하고, 미래 가격을 진입 판단에 사용하지 않는 단일 종목 연구용 엔진이다.

## 체결 규칙

- 신호가 확정된 다음 거래일 시가에 시장가로 진입한다.
- 매수 체결가는 시가에 매수 슬리피지를 더하고, 매도 체결가는 청산 기준가에서 매도 슬리피지를 뺀다.
- 수수료는 매수·매도 양쪽에, 세금은 매도에 적용한다.
- 일봉 안에서 손절과 익절 가격이 모두 닿으면 세부 순서를 알 수 없으므로 손절을 먼저 적용한다.
- 손절, 익절, 최대 보유기간, 테스트 종료 순으로 포지션을 청산한다.
- 주문 금액은 당시 가용 현금과 설정한 포지션 비율을 기준으로 계산하며 소수점 수량은 버린다.

## 실행 API

`POST /api/kiwoom/backtests`

```json
{
  "code": "005930",
  "startDate": "2025-01-01",
  "endDate": "2026-08-21",
  "initialCapital": 10000000,
  "positionSizeRate": 0.2,
  "feeRate": 0.00015,
  "taxRate": 0.0018,
  "slippageRate": 0.001,
  "stopLossRate": 0.08,
  "takeProfitRate": 0.15,
  "maxHoldingDays": 20,
  "boxRangeDays": 60
}
```

선택 설정을 생략하면 위 예시의 기본값을 사용한다. 결과에는 거래별 비용·순손익과 최종 자산, 승률, 기대값, 총수익률, 최대 낙폭이 포함되고 실행·거래 내역은 DB에 보존된다.

## 한계와 다음 단계

현재 엔진은 일봉 기반 단일 종목 연구 모델이다. 상·하한가, VI, 거래정지, 호가 단위, 거래량 대비 체결 한도, 여러 종목의 현금 경쟁은 아직 반영하지 않는다. 다음 단계의 워크포워드 검증에서는 기간 분리와 전체 시장 포트폴리오 모델을 추가한다.
