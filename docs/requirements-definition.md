# 요건 정의서

최종 수정일: 2026-08-29
대상: Kiwoom 한국 주식 스윙 자동매매 시스템
문서 상태: 초안 기준선 v0.1

## 1. 사업 목표

한국 주식 전체에서 급락 후 장기간 가격이 안정되고 간헐적으로 거래량이 증가한 뒤, 최근 일부 회복과 눌림이 나타난 종목을 찾아 스윙 방식으로 매수·보유·매도하는 시스템을 만든다. 연구와 PAPER 검증을 거쳐 최종적으로 사용자 PC에서 키움 실계좌 주문을 안전하게 자동 수행한다.

성공은 단순히 후보를 잘 찾는 것으로 판단하지 않는다. 비용 반영 후 반복 가능한 성과, 통제 가능한 손실, 주문·잔고의 정확성, 장애 후 안전한 복구가 함께 충족되어야 한다.

## 2. 사용자와 운영 조건

- 주 사용자: 시스템 소유자 1명
- 운영 환경: 사용자 Windows PC, Spring Boot 서버, React 화면, PostgreSQL
- 시장: KRX 한국 주식 현물 보통주
- 매매 방향: 현금 매수와 보유 수량 내 매도
- 보유 방식: 당일 청산을 강제하지 않는 스윙 매매
- 운전 단계: `신호 관찰 → PAPER → 키움 모의투자 → 제한적 실전 → 실전 자동 운전`

## 3. 범위

### 포함

- 종목 마스터·일봉·장중 시세 수집과 품질 검사
- 현재 유효한 패턴 후보 탐지, 순위화와 근거 제공
- 전략 버전 관리, 백테스트, 워크포워드와 PAPER 평가
- 계좌·잔고·주문·체결 동기화
- 진입, 손절, 익절 또는 전략 청산과 포지션 관리
- 실전 자동매매 ON/OFF, 위험 통제, 킬 스위치
- 장 전 준비, 장중 감시, 장 후 대사·성과 기록
- 모든 판단·주문·오류의 감사 기록

### 제외

- 선물, 옵션, ELW, 공매도, 신용·미수
- 해외 주식과 가상자산
- 타 사용자 계정, 다중 테넌트, 공개 서비스 배포
- 수익 보장 또는 손실 없는 매매

- 초기 실전 운용 원금
- 주문당 최대 손실액과 종목별 최대 비중
- 하루·월간 최대 손실액 또는 손실률
- 계좌 최대 낙폭과 연속 손실 허용 횟수
- 최대 동시 보유 종목과 총 투자 비율
- 손실 한도 도달 후 재개 조건

월 목표 수익은 보고 지표로만 사용하며 주문 확대 조건으로 사용하지 않는다.

## 7. 실전 전 필수 통과 조건

1. 키움 실전 주문 계약과 호출 제한이 공식 자료 및 소량 현장 시험으로 확인된다.
2. 모의투자에서 부분 체결, 거부, 타임아웃, 정정·취소와 재시작 대사가 검증된다.
3. 선택 전략이 미래 데이터 누수 없는 검증과 충분한 PAPER 관찰 기준을 통과한다.
4. 주문·체결·잔고 불일치가 자동 감지되고 신규 매수가 차단된다.
5. 킬 스위치, 손실 한도, 데이터 지연, API 중단 시험이 통과한다.
6. 제한된 금액과 종목 수의 실전 관찰 단계를 통과하기 전 규모를 확대하지 않는다.

## 8. 미결정·연구 항목

- “급락”의 최소 하락률과 기간
- 부분 회복의 기준값(현재 가설: 과거 하락폭의 약 20%, 탐색 범위 15~30%)
- 눌림 깊이, 거래량 감소 조건과 진입 타이밍
- 안정 구간의 통계적 판별법과 허용 변동폭
- 손절·익절·추세 이탈·최대 보유기간의 조합
- 종목 유동성, 거래정지·관리종목·ETF/ETN 제외 정책
- 실전 초기 위험 한도와 주문 가격 방식

이 값은 고정 요구사항이 아니라 데이터로 검증하고 전략 버전으로 관리한다.
