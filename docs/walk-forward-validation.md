# 워크포워드 검증

고정된 전략 설정을 시간순 학습 구간과 이후 검증 구간에 적용하고, 두 구간을 앞으로 이동하며 반복 평가한다. 미래 검증 데이터는 이전 학습 구간의 신호 계산이나 결과에 포함되지 않는다.

## 실행 API

`POST /api/kiwoom/backtests/walk-forward`

```json
{
  "backtest": {
    "code": "005930",
    "startDate": "2022-01-01",
    "endDate": "2026-08-21",
    "initialCapital": 10000000,
    "feeRate": 0.00015,
    "taxRate": 0.0018,
    "slippageRate": 0.001
  },
  "trainingDays": 240,
  "validationDays": 60,
  "stepDays": 60
}
```

기본값은 학습 240거래일, 검증 60거래일, 이동 60거래일이다. 전체 기간에 학습 구간과 검증 구간 하나를 만들 수 없으면 실행을 거부한다.
검증 거래가 여러 구간에 중복 집계되지 않도록 이동 기간은 검증 기간 이상이어야 한다.

## 보고 지표

- 각 구간의 학습 수익률과 검증 수익률
- 검증 거래 수, 승률, 비용 후 기대값
- 검증 최대 낙폭
- 같은 검증을 수수료·세금·슬리피지 0원으로 계산한 결과와의 자산 차이

기본 연구 통과 표시는 검증 구간 2개 이상, 검증 거래 5건 이상, 비용 후 기대값 양수, 최대 낙폭 -20% 이내를 모두 만족할 때만 나온다. 이 표시는 자동매매 승인이나 수익 보장이 아니다.

현재 단계는 고정된 설정의 시간 안정성을 확인한다. 다음 연구에서는 학습 구간에서 설정 후보를 선택한 뒤, 한 번도 사용하지 않은 검증 구간에 적용하는 매개변수 탐색과 전체 시장 포트폴리오 비교가 필요하다.
