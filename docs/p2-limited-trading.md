# P2 제한 매매 사용법

P2는 자동으로 실계좌 주문을 보내는 단계가 아니다. 후보를 저장하고 사용자가 화면에서 승인한 뒤에도 현재는 로컬 `PAPER` 주문만 체결한다.

## 안전 한도

- 주문당 최대 금액: 100,000원
- 최대 보유 종목: 1종목
- 일일 주문: 최대 2회
- 승인 확인 문구: `APPROVE_LIMITED_TRADE`
- 기존 종목 비중·총 투자 비중·일일 손실·누적 낙폭 한도를 추가로 적용한다.
- 주문 규모는 성과와 무관하게 자동 확대하지 않는다.

## 사용 순서

1. 전략 신호 발생 시 `POST /api/trading/limited/candidates`로 후보와 만료 시각을 기록한다.
2. 화면의 **매매 승인** 탭에서 코드, 이유, 기준가, 수량을 확인한다.
3. **PAPER 주문 승인** 또는 **거절**을 선택한다.
4. 승인 요청은 `APPROVE_LIMITED_TRADE` 확인 문구를 포함하며, 서버가 모든 한도를 다시 검사한다.
5. 승인 결과는 고유 신호 ID에 연결돼 재시도 시에도 중복 주문이 생기지 않는다.

## 성과 저하 감시

체결 후 예상가, 실제 체결가, 비용 후 순수익률을 `POST /api/trading/limited/performance`로 기록한다. `GET /api/trading/limited/performance`에서 누적 상태를 조회한다.

표본이 5건 이상인 상태에서 다음 중 하나가 발생하면 킬 스위치가 자동 활성화된다.

- 평균 절대 슬리피지가 1%를 초과
- 비용 후 평균 수익률이 0보다 작음

재개는 원인을 검토한 뒤 기존 수동 재개 API와 확인 문구를 사용해야 한다.

## 실제 주문 전 남은 검증

- P1의 실제 20거래일 관찰을 먼저 완료한다.
- 키움 모의투자에서 제한 정책과 주문 대사를 반복 검증한다.
- 실제 주문 어댑터 연결과 `LIVE` 활성화는 별도 변경·검토·사용자 승인으로 진행한다.
- 본 P2 구현만으로 실제 주문은 전송되지 않는다.
